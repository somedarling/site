よもよも帳 投稿管理

GitHubの権限を限定したトークンで、記事と画像を直接保存します。記事の削除や画像の取り外しでは、未使用の添付画像を自動的に削除します。通常はトークンを保存しません。「この端末に記憶する」を選んだ場合のみブラウザ内に保存します。共有端末では使わないでください。

1. GitHubに接続

対象リポジトリ：somedarling/site、Repository permissions → Contents: Read and write のみ。トークンは絶対に記事やGitHubのファイルに貼り付けないでください。

保存済みのトークンを端末から消すときは「保存したトークンを消去」を押してください。

記憶すると次回から入力を省けます。ただし端末やブラウザのデータにアクセスできる人、管理画面で実行された不正なスクリプトに読み取られる危険があります。共有端末では使用しないでください。

2. 新しい記事

画像は1枚あたり最大約4MB（GitHub API経由）。大きな画像はiPhone側で縮小してから選んでください。画像のアップロードは記事保存時に行います。

3. 記事一覧

保存後、GitHub ActionsによるNekowebへの反映には少し時間がかかります。
